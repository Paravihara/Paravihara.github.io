# 东辕西辙

“东辕西辙”是一组从现代科学与东方智慧之间往返阅读的文章。它不试图把佛法简化成科学，也不把科学包装成佛法，而是从控制论、复杂系统、认知与缘起法的交汇处，追问我们所经验的世界如何形成，又如何止息。

中文页面是陆续整理中的译稿。完整的英文书稿已经按照书籍结构整理为“a few words”、目录与章节页面，可以从[英文完整书稿](/en/talks/dong-xi-zhi/)进入。

全系列共 16 篇，适合按顺序慢读。前几篇建立认知与控制论的语言，中段把这些线索带回现实议题，后几篇逐渐转向缘起、涅槃与实修。
